THE ENGINEERING CHOICES

A model is only one part of the project.

01 / Prevent leakage

Casualty severity, injury details, casualty counts and accident cause are excluded. Identical selected-feature profiles stay within a single split, even with conflicting labels.

02 / Fit only on train

Imputation, scaling and one-hot encoding live inside a scikit-learn Pipeline. Validation selects the model; the test split never trains it.

03 / Examine weak classes

Majority baseline, macro-F1, balanced accuracy, per-class recall, confusion matrix and a stratified bootstrap interval make imbalance visible.

04 / Keep limits visible

There is no independent temporal or geographic validation. This dataset is retrospective and rare fatal cases limit confidence. Do not use it for safety decisions.
