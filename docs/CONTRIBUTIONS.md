# Genuine GitHub contribution attribution

Only real implementation commits are made, with their actual current timestamps. No empty activity commits, backdating or rewriting history to simulate work.

GitHub's contribution guidance requires an account-associated author email (or the account's GitHub-provided noreply email), a standalone repository rather than a fork, and the commit on the default or `gh-pages` branch. This project uses the owner's standalone repository and default `main` branch. The remote commit's resolved author login is checked after pushing; the check does not prove the graph refreshed immediately.

[GitHub's official troubleshooting guidance](https://docs.github.com/en/account-and-profile/how-tos/contribution-settings/troubleshooting-missing-contributions) notes that eligible contributions can take up to 24 hours to appear. Private contribution visibility is a separate profile setting; this repository's visibility is selected by the owner. No profile setting is silently changed.

AI assistance is disclosed in the README. An attributed engineering commit is not a claim that its code was written without assistance.
